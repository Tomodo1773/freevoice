# レビュー観点の読み込み

CLAUDE.md の「実装方針」セクションを Read で読み直し、そこに書かれた方針をレビュー観点として適用すること。

特に以下を必ず問う：

1. この変更が加えるケース個別対応に、個別対応する価値があるか（一律の単純挙動で困らないか）
2. 必要なケースをガードや約束事で守っていないか（構造的に発生しえない設計になっているか）
